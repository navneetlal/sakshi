# Test fixtures

Short meetings with known speakers, built from openly licensed audio by
`cargo xtask fixtures`. The generator downloads its sources once into
`target/fixture-sources/`, checks each against a pinned SHA-256, and writes
the files below. Regenerating needs ffmpeg and about 400 MB of downloads.

The end-to-end tests run the real pipeline on these folders; see the README
for how to run them.

## `ami-en2002d/`: English, four participants, 60 s

| File | Contents |
|---|---|
| `system.wav` | Headsets 1, 2, and 3 mixed: the remote participants FEO072, MEE071, MEE073 |
| `mic.wav` | Headset 0 (FEO070, playing "You") plus the remote mix at gain 0.3 (about −10.5 dB), standing in for audio from the speakers leaking into the mic |
| `recording.mp4` | Synthetic 640x360 video: SMPTE bars, a color chart, and an RGB test pattern for 20 s each, so key frames are expected at 0, 20, and 40 s |
| `reference.rttm` | Reference speaker turns (AMI speaker ids, times relative to the excerpt) |
| `reference.json` | Reference words per speaker turn |

- **Audio source:** [AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/corpus/),
  meeting EN2002d, individual headset channels `EN2002d.Headset-{0..3}.wav`,
  60 s from 2132.5 s. Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Changes: excerpted, mixed, and resampled to 16 kHz mono PCM16.
- **Headset to speaker:** found by mean loudness during each speaker's
  reference turns (each wearer's own channel is at least 15 dB louder):
  0 = FEO070, 1 = FEO072, 2 = MEE071, 3 = MEE073.
- **References:** `test_files/diar/ami_en2002d_2132.{rttm,json}` from
  [NeMo-Speech.cpp](https://github.com/NVIDIA/NeMo-Speech.cpp) v0.2.0
  (Apache-2.0). They derive from the AMI manual annotations (CC BY 4.0) and
  [AMI-diarization-setup](https://github.com/BUTSpeechFIT/AMI-diarization-setup)
  (Apache-2.0).
- **Video:** generated by ffmpeg's `lavfi` test sources; no third-party
  content.

## `fleurs-hi/`: Hindi, two speakers, 22 s

| File | Contents |
|---|---|
| `system.wav` | A female speaker's utterance, 1 s of silence, then a male speaker's utterance |
| `reference.tsv` | Turn order, FLEURS utterance id, speaker gender, and reference transcription |

- **Source:** [Google FLEURS](https://huggingface.co/datasets/google/fleurs)
  `hi_in` dev split at revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`,
  utterances `5958463932227431376` (female) and `14584887621258891555`
  (male). Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Changes: concatenated with silence and converted to PCM16.
- FLEURS has no speaker ids, so one female and one male utterance were
  chosen to guarantee two different speakers. There is no `mic.wav`; the
  pipeline handles a missing track.
